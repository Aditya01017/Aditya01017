## Featured project: [IoT Asset Dashboard](https://github.com/Aditya01017/iot-dashboard)

A full-stack dashboard for tracking connected hardware assets.

- **API:** Express 5 and Mongoose, with JWT-protected routes and bcrypt password hashing.
- **Querying:** server-side pagination, status filtering, and case-insensitive name search, returning page counts to the client.
- **Data model:** assets carry type, health, tags, alarm counts by severity, and latitude/longitude.
- **Client:** React 19, React Router, and Axios, with protected routes and a shared API client.

Stack: React · Vite · Node.js · Express · MongoDB · JWT · MIT licensed
